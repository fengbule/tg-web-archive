# TG Web Archive · Telegram 视频管理器

**在浏览器里收发 Telegram 消息，把频道视频保存到服务器，随时播放或下载到手机、电脑。**

中文界面，支持手机、平板和电脑。适合个人部署和使用。

## 能做什么

| 功能 | 说明 |
| --- | --- |
| 下载视频 | 浏览频道封面、批量选择，支持暂停、继续和断点续传 |
| 在线播放 | 默认原画，支持拖动预览、倍速、选集和记忆进度 |
| 管理媒体 | 搜索、收藏、整理视频，单个下载或批量打包到本机 |
| 收发消息 | 查看会话、发送与回复消息、与机器人互动 |
| 管理频道 | 查找、加入或退出频道和群组 |
| 多账号 | 扫码或手机号登录，切换账号、结束会话、加密备份与迁移 |

**存储方式：**频道下载保存在服务器，关闭网页仍会继续；选择“另存到手机 / 电脑”才会下载到你的设备。

## 快速开始

准备一台 Linux 服务器，安装 Git、Python 3、Docker Engine 和 Compose 插件，确认 `8080` 端口空闲。

```bash
git clone https://github.com/fengbule/tg-web-archive.git
cd tg-web-archive
sudo bash scripts/manage.sh install
```

1. 按提示设置后台管理员密码。
2. 打开 `http://服务器IP:8080`，输入密码进入后台。
3. 添加 Telegram 账号，配置 API ID / API Hash 后扫码或手机号登录。已有配置可复用，扫码仍需手机确认。

使用 InstaBox 时，请改用 [InstaBox 部署指南](docs/INSTABOX.md)，它采用独立端口和数据目录。

## 使用须知

- 仅能访问当前 Telegram 账号有权查看的内容，不绕过内容保护。
- 单管理员系统，不包含语音 / 视频通话和秘密聊天；不兼容的视频可下载原文件播放。
- 公网使用请配置 HTTPS；不要分享后台密码、`.env`、Session、数据库或账号备份文件。
