# 使用指南

[返回项目首页](../README.md)

## 账号登录与迁移

在“管理账号”中添加账号，首次使用时填写 Telegram API ID / API Hash，再选择扫码或手机号登录。已有应用配置可复用；扫码需要手机 Telegram 确认，有两步验证时还需输入对应密码。

使用账号选择器切换账号。各账号的 Telegram Session 独立，已开始的下载任务仍由发起账号完成。

- **结束会话**：撤销指定账号在本应用中的 Telegram 登录，保留其他账号和服务器已下载的视频；撤销失败时保留授权供重试。
- **导出账号**：选择账号，验证管理员密码，再设置独立备份密码，下载加密的 `.nebula` 文件。
- **导入账号**：上传备份，输入本服务器管理员密码与备份密码。只新增账号，重复授权会跳过。

账号备份不含视频、聊天记录或后台密码，不能代替整站备份。迁移时停止旧实例使用该授权，避免两台服务器同时连接。已经结束的会话不能用旧备份恢复。

## 下载频道视频

选择账号和频道，按封面、消息说明挑选视频，勾选后加入下载队列。列表支持搜索、已下载状态筛选和继续下滑加载。

- **暂停**保留已下载部分；**继续**从已有进度恢复。
- 断网或服务重启后，任务会重新排队并保留临时文件。
- **取消并删除临时文件**会放弃当前进度，操作前会要求确认。

频道下载保存在服务器，关闭网页不会停止任务。速度取决于 Telegram 限制、服务器线路和磁盘情况；并发参数不保证越高越快。

## 播放与下载到本机

在媒体库打开视频，播放器默认使用原画。

- 轻点画面显隐控制栏，通过播放 / 暂停按钮控制播放。
- 拖动进度条或在手机画面横滑定位，可查看切片预览；首次生成预览可能需要等待。
- 支持倍速、记忆进度、画中画、全屏、方向锁和上一集 / 下一集；部分能力受浏览器限制。
- 如需节省带宽，可手动生成并选择 480P 流畅版；它额外占用服务器空间，不覆盖原画，也不会因缓冲自动切换画质。

媒体库或播放器中的下载按钮可将文件保存到手机 / 电脑。勾选多个视频可批量打包 ZIP；保存位置由浏览器决定。不兼容的编码可下载原文件，用本机播放器打开。

封面优先使用 Telegram 自定义视频封面或同相册照片，再使用视频缩略图；可在媒体库同步封面。标题优先显示消息说明，也可展开查看文件名。

## 收藏与整理

在频道、媒体库或播放器中点击星标，将视频加入本应用的“视频收藏夹”；它与 Telegram 的“收藏夹消息”分别保存。

媒体库支持搜索、排序、重命名和批量删除。删除会清理服务器中的关联文件与记录，不会删除 Telegram 原消息；清空全部会影响所有账号的本地媒体，操作前请确认。

## 消息与频道

打开侧栏的“Telegram 客户端”，选择账号与会话，可查看历史、搜索消息、发送与回复文字，编辑或删除自己发送的消息。也可置顶、归档、静音或标记已读。

- 输入用户名或链接查找频道、群组与机器人，先预览，再确认加入或启动。
- 退出频道或群组需要确认；有审批的邀请会显示申请状态。
- 从服务器媒体库选择视频发送，后台队列显示进度；受保护来源不可重新发送。
- 向 Telegram 收藏夹发送视频，可使用媒体库的“上传收藏夹”入口。

消息权限和机器人能力受 Telegram 限制。通话、秘密聊天和复杂小程序请使用官方客户端。

## 界面与密码

顶栏支持明暗主题，以及手机、平板、电脑布局切换。

系统设置中可以修改后台密码，保存后旧登录失效。查看 API 凭据需要密码验证，也可设置独立的查看密码。忘记后台密码时，请参考 [运维指南](../scripts/README-小白运维.md)。
